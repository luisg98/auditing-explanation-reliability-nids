# Artifact provenance

The package accompanies *Trust in Neural Intrusion Detection: Auditing
Post-hoc Explanation Reliability*. It rebuilds reported results from frozen
source-level records and does not claim to rerun model training.

The paper outputs, source records, selected configurations, and analysis
scripts are identified by the SHA-256 inventory in `PUBLICATION_MANIFEST.json`.
The analysis manifest generated by `scripts/revision_reproduce.py` records the
input hashes for this exact candidate tree.

For packaging, all 12,774 distinct `flow_id` values were replaced by
independent random 128-bit IDs. No mapping was kept. The direct row locators
(`source_file`, `source_row`, `sample_order`) and raw/tensor fingerprints were
removed from the relevant per-flow records. These IDs preserve grouping within
the included analyses; no numerical row or result was filtered. This removes
the direct linkage demonstrated in the earlier candidate, but is not a claim of
anonymity and does not exclude matching through other detailed measurements or
external copies. The proposed release snapshot is a new root commit with no parent, old tag, or
inherited repository history. The existing private repository history remains
unchanged; the clean snapshot is local and has not been pushed.

Removing source-order keys changed the deterministic ordering used for the
paired source bootstrap. Its point estimates are unchanged; bootstrap interval
endpoints were recalculated from the released IDs and the manuscript was
updated to those endpoints. The analysis manifest fixes the resulting frozen
record inputs and rebuild output.

The rebuild check compares regenerated numerical tables and figure data, but
does not establish data redistribution rights. See `docs/data-access.md` for
the specific unresolved terms.

The following SHAP facts remain distinct:

- **Recorded:** the stored explanation accounts and their observed outputs.
- **Reconstructed:** coalition budget, repeated median background, and wrapper
  settings inferred from the saved configuration and implementation.
- **Unknown:** the exact historical SHAP version and effective `l1_reg` value.

The current pinned environment describes the record-rebuild tools. It is not
presented as the environment used for every historical experiment. Raw source
data and fitted checkpoints are not included; fresh inference requires those
inputs from their distributors and a separate run record.
